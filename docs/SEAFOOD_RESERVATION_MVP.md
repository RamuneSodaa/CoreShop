# Seafood Reservation MVP（卖鱼接龙版）

## 目标

把微信群里的人工接龙改成：鱼货展示 → 顾客选择数量 → 提交预订 → 自动占用库存 → 后台查看订单。

本阶段明确 **不接微信支付**。货款继续由顾客按微信群原方式微信转账，管理员线下确认。

## 第一阶段已完成

- 商品订单创建成功后，不再展示微信支付方式；原支付页改为“预订成功”页。
- 成功页显示订单号、预计金额、线下付款说明，并可进入订单详情。
- 关闭“未在线支付订单自动取消”定时任务，避免已预订鱼货被系统错误释放库存。
- 关闭“催付款”定时任务。
- CoreShop 原有下单库存冻结机制继续保留，因此顾客下单后可销售库存会减少。

## 当前约束

- CoreShop 原生购买数量和库存为整数，本阶段按 `1斤 / 2斤 / 3斤`、`1条 / 2条` 使用。
- 下一阶段再加入 0.5斤、1.5斤等小数斤库存方案。
- 当前仍保留 CoreShop 其他商城页面和后台功能，后续会逐步隐藏不需要的支付、优惠券、积分、分销、拼团等入口。

## 下一阶段

1. 新做“今日鱼货”极简首页：鱼名、图片、会员价、剩余库存、加减数量、提交预订。
2. 后台精简为商品 / 库存 / 订单 / 用户四个主要模块。
3. 将界面中的“件”统一改成按商品单位显示“斤 / 条”。
4. 增加订单状态：已预订 → 已收款 → 已配货 → 已取货 / 已寄出 → 已取消。
5. 做并发库存测试，确保多人同时接龙时不会超卖。
